# Audio public de démonstration — pas une voix personnelle

Ces20WAV sont des **synthèses** françaises produites par JARVIS à partir du conditionnement public Alba, pas un enregistrement personnel ni une prise de parole réelle d'Alba. Source : démonstration native VOICE05, cinq premières phrases publiques, même identité publique/graine42/LSD3/temp0,3. Les fichiersNEUTRAL sont des copies exactes des WAV05 aux SHA épinglés ; JOY/SURPRISE/CALM appliquent uniquement les enveloppes d'énergie logicielles décrites dans le rapport.

**Les noms désignent des intentions d'expérience, pas des émotions validées.** Aucune écoute humaine n'est revendiquée. Pour une première comparaison, écouter neutral-1.wav puis joy-1.wav/surprise-1.wav/calm-1.wav à volume identique. Un changement de volume n'est pas une preuve d'émotion ni de naturel. Les quatre autres phrases servent à vérifier la stabilité. Une étude aveugle doit masquer les noms et contrebalancer l'ordre avant de demander l'émotion reconnue.

Les SHA, métriques, durées exactes et flagsfalse de validation humaine sont dans ../proofs/PUBLIC-DSP.json. Le profilB de l'utilisateur n'a jamais été utilisé ni envoyé au Cloud.

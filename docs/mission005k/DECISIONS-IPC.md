# 005K — recommandation soumise, pas d’activation

Orientation hybride approuvée ; détails ci-dessous **non approuvés**. Aucune nouvelle APK bridge, service, permission, binding Android ou requête CORE réelle dans cette mission. L’adaptateur JVM en mémoire reste la référence de contrat ; il ne prouve ni identité Android ni arbitrage global.

| Option | Données, sécurité et isolation | API, RAM et déploiement | Avis |
|---|---|---|---|
| Bibliothèque intra-app | Appels directs, aucune surface IPC ; même sandbox, autorité à maintenir dans CORE | CORE24/25 nécessite garde API26 ; risques natifs/packaging, migration de profil/signature, modèles résidents à arbitrer | Bon adaptateur logique, ne pas intégrer au CORE installé ici |
| Bound Service explicite Binder/AIDL | Profil/PCM restent dans VOICE, DTO bornés ; service futur exporté seulement après authentification, binder UID + package + certificat/ligne de signature et grant exact/session | APK indépendantes ; coût de deux processus et modèles ; foreground visible, mort Binder, limites arrière-plan/audio focus à traiter ; min26 côté VOICE | **Candidat recommandé pour un pilote opt-in distinct**, sous les décisions ci-dessous |

## Décisions concrètes à approuver avant missions CORE/VOICE

1. **Transport/déploiement** : conserver J comme repli stable ; futur pilote dans une application VOICE distincte, Bound Service explicite + confirmation locale. Pas de changement du manifeste J. Qualification API26+, jamais hausse du min24 CORE ; API24/25 garde TTS ancien sous contrôle explicite.
2. **Confiance/signatures** : relever sur appareil les certificats publics réellement installés, sans exporter de clé. Si même clé déjà prouvée, permission signature + contrôle UID/méthode ; sinon appairage visible avec liste package/certificat/grant local. Ne pas croire une chaîne de package, authorization_ref, nonce ou permission déclarée. Éviter de re-signer une ancienne app pour contourner une incompatibilité. Contrôle Binder.getCallingUid au point d’entrée, avant clearCallingIdentity, sur chaque opération ; rotation/révocation, UID partagé, certificat divergent et réinstallation refusés par défaut. Permissions signature seules ne fonctionnent pas entre signataires distincts. L’appairage n’est pas implémenté ni validé ici.
3. **Arbitre global** : autorité future côté CORE (choix recommandé), émission/génération des baux associées à session/corrélation ; CORE doit obtenir preuve d’arrêt **et de déchargement** LLM/Whisper avant admission VOICE. VOICE conserve ses propres gardes 2 Gio et thermiques ; une déclaration de mémoire n’alloue pas la RAM. Aucune extension du coordinateur LLM actuel présumée. Un arbitre vivant seulement dans CORE exige gestion de son décès : VOICE annule, reste bloquée jusqu’au nettoyage confirmé ; pas de fail-open ni reprise concurrente. La portée et le mécanisme de preuve restent à valider.
4. **Cycle de vie/audio/fallback** : activation opt-in, client absent/version incompatible → erreur visible, jamais appel implicite au TTS. Confirmation locale et profil exact ; service lié seulement pendant opération visible, pas de démarrage arrière-plan permanent, service foreground à qualifier sous restrictions Android35 si nécessaire. Focus audio refusé/perdu → arrêt, pas succès audible. Repli TTS ancien seulement après preuve que VOICE n’émet plus, sans recalcule/double voix automatique. Rollback par désactivation du bridge, J et CORE historiques inchangés.
5. **Contrat proposé** : version locale 005k.1 expérimentale, schémas UNIFIED 1.0/1.0.0 épinglés en lecture seule ; préciser officiellement référence du pack, résolution privée du texte, contexte/session de réponse et liaison du bail. Les ajouts ne sont pas injectés dans les schémas fermés UNIFIED. Valider le hash commun avant missions liées ; aucune modification UNIFIED dans cette mission.

Les rapports et tests sont livrés avant cette décision. Ne pas redemander l’approbation de l’orientation ADR ; seuls ces choix techniques restent ouverts. L’implémentation permise ici s’arrête à la simulation/au harness de mesure. Aucun besoin de transmettre le profil B ou d’installer une application pour étudier ces décisions.
